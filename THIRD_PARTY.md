# Third-party projects

Axon Auto Agent is an independent community project. It is not an official DeepSeek
product and is not affiliated with Andrej Karpathy.

## DeepSeek Harness

- Project: <https://github.com/deepseek-ai/deepseek-harness>
- Role: planned upstream agent runtime and plugin platform
- License: MIT
- Integration policy: versioned dependency and out-of-tree profile/plugins; no upstream
  source is currently copied into this repository

DeepSeek Harness is in developer preview and warns of compatibility-breaking changes.
Axon Auto Agent support claims must name the exact tested DSH version.

## autoresearch

- Project: <https://github.com/karpathy/autoresearch>
- Role: conceptual reference for constrained autonomous experimentation
- License: MIT
- Reused principle: fixed boundaries, measurable evaluation, keep/discard decisions,
  iteration history, and automatic continuation

No autoresearch source code or training assets are currently copied into this repository.
Future examples that adapt its code must retain the appropriate license notice.
