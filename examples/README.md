# Examples

Examples must be reproducible vertical slices, not screenshots of a successful chat.
Each future example includes fixed fixtures, allowed mutations, budget, evaluator,
expected artifacts, failure cases, and a replayable run record.

- [ ] Add one bounded software or research optimization loop inspired by
  autoresearch.
- [ ] Add one document/data deliverable whose completion is checked by
  structure and source evidence.
- [ ] Add one external action flow that demonstrates contextual approval
  and denial without side effects in the default fixture.
